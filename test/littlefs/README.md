# Step1 Install littlefs-tools
```shell
pip install littlefs-tools

# If you use Ubuntu 24.04, you need to add --break-system-packages to install littlefs-tools.
# pip install littlefs-tools --break-system-packages

```
# Step2 Generate littlefs.bin and download to flash
```shell
# Linux
./generate.sh

# Windows
generate.bat
```
